# Промпты

Проект собирается двумя промптами в Claude Code, в пустой папке.

## 1. Установка: Spec-Driven Company и бот в облаке Convex

Промпт «Telegram-бот · Convex» из стартера Spec-Driven Company — целиком на странице
[spec-driven-company/lang/ru](https://github.com/eugeneshilow/spec-driven-company/tree/main/lang/ru#readme)
(таблица стеков, строка «Telegram-бот · Convex»). Он ставит правила проекта и собирает бота,
который живёт в облаке Convex на бесплатном тарифе. Вход в Convex и создание бота у @BotFather
делаете вы сами; ключ бота никогда не проходит через чат.

## 2. Запись клиентов к мастеру

```text
Сделай из этого бота бота для записи клиентов к мастеру. Максимально просто.

Клиент
- /start → «Привет! Выберите день» → кнопки на 7 дней вперёд.
- Выбрал день → кнопки свободных часов.
- Нажал час → «Записал вас: пятница, 15:00». Кнопка «Отменить запись».

Мастер (его Telegram ID — в переменных Convex, MASTER_ID)
- Каждая новая запись и отмена сразу приходят ему: «Иван, пятница 15:00».
- /записи — список на неделю.

Свободное время
- Константы в коде: работа пн–сб с 10:00 до 20:00, запись на 1 час, время московское.
- Свободные часы = все часы рабочих дней на 7 дней вперёд,
  минус занятые записями, минус уже прошедшие.
- Нельзя записать двоих на одно время. У одного клиента — одна активная запись.

Проверь сам: запись, отмена, попытка занять занятое время, запись на прошедшее время.
Не делай: несколько услуг, оплату, напоминания, сайт — это следующие шаги.
```

Свой Telegram ID (для `MASTER_ID`) — у бота [@userinfobot](https://t.me/userinfobot): напишите ему /start.

# shilovtech-projects

> Learning projects from the Russian-language YouTube channel [shilovtech](https://www.youtube.com/@shilovtech). The texts are in Russian on purpose: they are part of the lessons.

Учебные проекты из роликов YouTube-канала [Шилов Тек](https://www.youtube.com/@shilovtech). Каждый проект собран в ролике с нуля агентом Claude Code — обычными промптами, без готовых заготовок. Одна папка — один проект.

## Проекты

| Проект | Что это | Ролик |
| --- | --- | --- |
| [telegram-booking-bot](telegram-booking-bot/) | Telegram-бот записи клиентов к мастеру: клиент выбирает день и свободный час, мастеру приходит уведомление. Живёт в облаке Convex, сервер не нужен. | скоро |

## Как взять проект себе

1. Скопируйте папку проекта к себе — или просто вставьте промпт из её `PROMPT.md` в Claude Code в пустой папке, и агент соберёт проект заново.
2. Ключей в репозитории нет: бота каждый создаёт у [@BotFather](https://t.me/BotFather), проект Convex — на своём бесплатном аккаунте.
3. Как запустить — в `docs/README.md` и `docs/telegram/README.md` внутри проекта.
